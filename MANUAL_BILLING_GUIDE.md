# Manual Billing Guide (Without Barcode Scanner)

## ✅ Yes, the app works perfectly without a barcode scanner!

The application is designed to work **fully functional** without any hardware. You can browse products manually and add them to billing in multiple ways.

## Ways to Add Products to Billing

### Method 1: Search by Product Name (Recommended)

1. **Go to Billing Screen**
   - Tap on "Billing" from dashboard or menu

2. **Type Product Name**
   - In the search box, start typing the product name
   - Example: Type "cotton" to find all cotton products
   - The search is **real-time** - results appear as you type

3. **Select Product**
   - Tap on any product from the search results
   - Product is automatically added to cart

**Example:**
- Type: `saree` → Shows all saree products
- Type: `silk` → Shows all silk products
- Type: `red` → Shows products with "red" in name

---

### Method 2: Search by Barcode Number

1. **Type Barcode**
   - In the search box, type the barcode number
   - Example: `1234567890123`
   - Product with matching barcode appears

2. **Select Product**
   - Tap on the product to add to cart

**Note:** You can type barcode numbers manually - no scanner needed!

---

### Method 3: Browse All Products (Easiest)

1. **Tap Browse Button**
   - Look for the **list icon** (☰) next to the search box
   - This button shows "Browse All Products"

2. **View All Products**
   - All products in inventory are displayed
   - Shows product name, barcode, stock, and price

3. **Select Product**
   - Scroll through the list
   - Tap any product to add to cart

**Best for:** When you want to see all available products at once

---

### Method 4: Barcode Scanner (Optional)

1. **Tap Scanner Icon**
   - Look for the **QR code scanner icon** (📷)
   - This opens the camera for barcode scanning

2. **Scan Barcode**
   - Point camera at barcode
   - Product is automatically found and added

**Note:** This is completely optional. You can ignore this button if you don't have a scanner.

---

## Complete Billing Flow (Without Scanner)

### Step-by-Step Process:

1. **Open Billing Screen**
   ```
   Dashboard → Billing (or tap 💰 icon)
   ```

2. **Add Products to Cart**
   - **Option A:** Type product name in search box
   - **Option B:** Tap "Browse All Products" button (list icon)
   - **Option C:** Type barcode number manually
   - Tap on product to add to cart

3. **Manage Cart**
   - View all items in cart
   - Adjust quantities using +/- buttons
   - Remove items using delete icon

4. **Select Customer** (Optional)
   - Open customer dropdown
   - Select existing customer or "Walk-in Customer"

5. **Set Payment Mode**
   - Choose: Cash, Card, UPI, or Bank Transfer

6. **Apply Discount** (Optional)
   - Enter discount percentage if needed

7. **Review Bill Summary**
   - Check subtotal, GST, and total
   - All calculations are automatic

8. **Save Bill**
   - Tap "Save Bill" button
   - Bill is saved with invoice number
   - Stock is automatically updated

## Tips for Faster Billing

### 1. Use Product Names
- Type first few letters of product name
- Example: Type "cot" to find "Cotton Saree"

### 2. Browse All Products
- Use browse button to see everything
- Useful when you don't remember exact name

### 3. Quick Add
- Products are added with quantity 1 by default
- Adjust quantity in cart if needed

### 4. Search Shortcuts
- Search by partial name: "silk" finds "Silk Saree", "Silk Fabric"
- Search by barcode: Type full barcode number
- Search is case-insensitive

### 5. Barcode Labels (No Scanner Needed)
- Go to **Inventory** → tap the barcode icon next to a product
- View the label, **Share / Save as PDF**, or **Print to Bluetooth** (if printer connected in Settings)

## Troubleshooting

### Issue: Can't find a product

**Solutions:**
1. Check spelling - search is case-insensitive but spelling matters
2. Use "Browse All Products" to see everything
3. Try searching by barcode number instead
4. Check if product exists in Inventory screen

### Issue: Search shows no results

**Solutions:**
1. Clear search box and try again
2. Use "Browse All Products" button
3. Check if products are added in Inventory
4. Try typing just first few letters

### Issue: Product not adding to cart

**Solutions:**
1. Make sure you tap on the product (not just the list item)
2. Check if product has stock available
3. Try again - tap the product card/row
